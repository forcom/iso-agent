# 검토 범위와 해석 원칙

이 문서는 절차서 14종과 양식 60종을 개정한 근거·대응 관계를 정리한 검토 자료이다. 회사의 실제 고영향 판정, 준수평가 결과, 방침, 평가, 승인 또는 이행 기록이 아니다. 실제 적용성·이행 여부는 각 절차를 수행하여 별도 산출물로 남긴다.

ISO/IEC 42001과 매뉴얼의 요구사항을 기준으로, 아래 세 자료의 개념·리스크 관리·윤리 지침을 회사의 실행 절차에 채택했다. ISO/IEC 22989는 개념·용어 표준, TR 24368은 윤리·사회 문제의 개요, ISO/IEC 23894 및 ISO 31000은 리스크 관리 지침이다. 이들 자료의 모든 설명·권고를 독립적인 인증 요구사항으로 바꾸지 않았다. 정기 주기, 승인 경로, 위험 행렬·수용 기준과 법령에 없는 보유 기산점은 회사가 채택한 운영 기준이다.

매뉴얼의 기능상 역할을 유지하고 실제 부서 분장은 절차에 둔다. 인공지능안전관리자는 담당 부서들이 분담하는 기능이며 모든 실무를 단일 담당자에게 집중시키지 않는다. 서비스별 목적·사용자·기술·법적 판정·운영 조건은 별도 기록에 두어 새로운 서비스에도 동일한 절차를 적용한다.
