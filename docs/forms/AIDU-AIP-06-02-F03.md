# 영향평가 결과 제공·갱신표

- 양식번호: AIDU-AIP-06-02-F03
- 근거: [AIDU-AIP-06-02](../procedure/AIDU-AIP-06-02.md)의 업무절차 및 5항

빈 양식 원본을 복사하여 별도 산출물·기록으로 작성한다. 실제 담당자·평가 결과·일자·승인 내용은 수행 근거에 따라 기입하고, 해당 없음은 사유를, 미확정은 확인 담당자·기한을 남긴다. 같은 내용의 상세표·연결 기록이 있으면 그 식별자와 위치를 기입할 수 있다.

제공·부분 제공·제한 판단의 근거와 승인된 요약본 버전을 명시한다. 수신자별 후속 질의와 반영 여부를 추적한다.
