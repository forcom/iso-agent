# 윤리 쟁점·대안 검토 및 이해관계자 협의서

- 양식번호: AIDU-AIP-06-02-F04
- 근거: [AIDU-AIP-06-02](../procedure/AIDU-AIP-06-02.md)의 업무절차 및 5항
- 목록: [문서양식 목차](README.md)

빈 원본을 복사하여 별도 기록으로 작성한다. 실제 수행·검토·승인만 기록하고 해당 없음은 근거를, 미확정은 담당자·기한·진행 제한을 기입한다. 복수 시스템·쟁점·의무는 행 또는 상세 기록을 반복하여 연결한다.

윤리 주제는 적용 맥락에 따라 검토하되 관련 없음의 이유를 남긴다. 고객 의견과 피영향자 의견을 구분하며 회사의 이익으로 중대한 권리 침해를 상쇄하지 않는다.
