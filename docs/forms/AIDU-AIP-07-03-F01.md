# 문서·기록 관리대장

- 양식번호: AIDU-AIP-07-03-F01
- 근거: [AIDU-AIP-07-03](../procedure/AIDU-AIP-07-03.md)의 업무절차 및 5항
- 양식 목록: [문서양식 목차](README.md)

본 양식을 복제하여 개별 산출물·기록으로 작성한다. 수행 근거에 따라 담당자·일자·검토 및 승인 결과를 기입하고, 비해당 항목은 사유를, 미확정 사항은 확인 담당자와 기한을 명시한다. 관련 상세 자료나 별도 기록이 있는 경우 해당 식별자와 저장 위치를 연결하여 기입할 수 있다.

공식 저장 위치와 유효 버전·접근 범위·보유 기준을 연결한다. 승인·시행일은 실제 승인과 배포 근거에 따라 기입한다.
