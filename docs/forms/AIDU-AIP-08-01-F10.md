# 고영향 AI·안전성 법정 책무 이행 확인서

- 양식번호: AIDU-AIP-08-01-F10
- 근거: [AIDU-AIP-08-01](../procedure/AIDU-AIP-08-01.md)의 업무절차 및 5항
- 목록: [문서양식 목차](README.md)

빈 원본을 복사하여 별도 기록으로 작성한다. 실제 수행·검토·승인만 기록하고 해당 없음은 근거를, 미확정은 담당자·기한·진행 제한을 기입한다. 복수 시스템·쟁점·의무는 행 또는 상세 기록을 반복하여 연결한다.

고영향 의무와 법 제32조 안전성 의무의 적용을 따로 판단한다. 적용하지 않는 항목은 근거를 기록한다. 법률상 노력의무·회사 의무·법정 필수 의무를 구분하고 계획만으로 이행 완료를 표시하지 않는다.
