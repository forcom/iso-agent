# 문서양식 목차

본 목차는 인공지능경영시스템(AIMS) 절차서 14종에 정의된 표준 문서양식 60종의 목록과 작성 기준을 정한다. 각 양식 원본을 복제하여 업무 수행에 따른 개별 산출물 및 기록을 작성하며, 양식 원본 자체에는 개별 평가·승인 결과를 기입하지 않는다.

동일한 관리 항목을 사내 협업 도구나 전자결재·이슈 관리 시스템에서 통합 관리하는 경우, 양식의 핵심 항목·검토·승인 이력과 양식 식별자(ID)의 대응 관계를 유지하여 본 양식을 갈음할 수 있다. 각 양식 내 `심층 검토 및 추적 항목 (해당 시 작성)`은 서비스 특성·리스크 수준·자체 학습 여부에 따라 비례적으로 작성하며, 해당하지 않는 항목은 사유를 간략히 표시하거나 생략할 수 있다. 작성된 기록의 보유·접근·폐기는 [정보 및 기록관리절차서](../procedure/AIDU-AIP-07-03.md)를 따른다.

신규·특수 검토 양식 중 법령 적용 판정([AIDU-AIP-04-01-F05](AIDU-AIP-04-01-F05.md))과 투명성·설명·감독 확인([AIDU-AIP-08-01-F09](AIDU-AIP-08-01-F09.md))은 시스템 도입 및 주요 변경 시 작성한다. 리스크 기준·협의 계획([AIDU-AIP-06-01-F06](AIDU-AIP-06-01-F06.md), 별도 기준 설정 또는 대외 협의 필요 시), 윤리 대안·협의([AIDU-AIP-06-02-F04](AIDU-AIP-06-02-F04.md), 중대한 기본권·윤리 충돌 또는 직접 협의 필요 시), 고영향·안전성 법정 책무 확인([AIDU-AIP-08-01-F10](AIDU-AIP-08-01-F10.md), 법 제34조 고영향 AI 또는 법 제32조 안전성 확보 대상 해당 시)은 해당 조건이 성립하는 경우에 한하여 작성하는 조건부 양식으로 운영한다. 관계기관에 제출하는 대외 민원·신청 문서는 해당 기관의 최신 법정 서식을 사용한다.

영향평가는 [영향평가 계획·범위서](AIDU-AIP-06-02-F01.md)(AIDU-AIP-06-02-F01)에 제품·서비스 정의·작동원리·판단 기준을 정하고, [영향평가서](AIDU-AIP-06-02-F02.md)(AIDU-AIP-06-02-F02)의 2항을 시나리오별로, 2.3항을 기본권·피영향 집단별로 반복하여 작성한다. [영향평가 결과 제공·갱신표](AIDU-AIP-06-02-F03.md)(AIDU-AIP-06-02-F03)에는 제공 근거·범위·구제 경로와 재평가에 따른 재통지를 연결한다. 기본권 영향의 관련성 판단과 현재 통제·판단 근거는 기본 작성 항목이며, 상세 자료는 유효한 기존 기록의 ID·버전·위치로 연결할 수 있다.
