# 문서양식 목차

절차서 14종에 정의된 양식 60종의 개별 Markdown 원본이다. 양식을 복사하여 실제 수행에 따른 별도 산출물·기록을 작성한다. 실제 방침·판정·평가·담당자·승인 결과는 빈 양식 원본에 입력하지 않는다.

양식 2.0은 표준·법령 반영 개정에 대응한다. 기존 기록을 소급하여 다시 작성하지 않고, 변경된 필드가 필요한 신규·재평가 활동에 적용한다. 동일 내용을 다른 시스템에서 관리할 때는 필수 필드·검토·승인과 양식 ID의 대응 관계를 유지한다. 보유·접근·폐기는 [정보 및 기록관리](../procedure/AIDU-AIP-07-03.md)를 따른다.

신규 양식은 법령 적용 판정(04-01-F05), 리스크 기준·협의 계획(06-01-F06), 윤리 대안·협의(06-02-F04), 투명성·설명·감독(08-01-F09), 고영향·안전성 책무(08-01-F10)이다. 법정 제출에는 해당 기관의 최신 법정 서식을 사용한다.
