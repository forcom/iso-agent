# 1 지침서 구성

### 1.1 이 목차는 [매뉴얼 문서체계](../manual/AIDU-AIM-01-01.md)에 지정된 지침서 2종의 적용 방법과 관련 절차·양식을 안내한다.

| 문서번호 | 지침서명 | 실무 내용 |
| --- | --- | --- |
| [AIDU-AIG-08-01](AIDU-AIG-08-01.md) | 인공지능경영활동관리규정 | 상황·법령 자료 수집, 리스크·SoA·영향평가 작성, 역할·목표·교육·문서 관리, 공급자·고객 자료, 연간 점검·심사·경영검토·시정조치 |
| [AIDU-AIG-08-02](AIDU-AIG-08-02.md) | 시스템 수명 주기 및 데이터 관리지침서 | 요구·설계, 데이터 품질·가명처리·분할, 외부 API·구현, 시험·지표, 고지·사람 감독, 배포·운영·변경·복구, 이의제기·삭제·종료 |

### 1.2 매뉴얼의 요구사항과 절차서의 책임·시점·판단·승인을 기준으로 업무를 수행하고, 지침서에서 구체적인 작성·점검·시험 방법을 찾는다. 지침서의 작업 질문이나 예시 지표만으로 상위 기준을 충족했다고 판단하지 않는다.

### 1.3 실제 방침, 목표, 담당자 지정, 평가·검증 결과, 고지문, 승인 및 운영 기록은 별도 산출물이다. 지침서의 작성안은 대표이사의 실제 승인과 시행 관리 이전에 시행본으로 표시하지 않으며, 승인·회람 이력은 [정보 및 기록관리절차서](../procedure/AIDU-AIP-07-03.md)에 따라 관리한다.

### 2.2 두 지침은 회사의 향후 서비스에도 적용한다. Edu Score의 교육 평가와 개인 학습 정보 보유 조건은 해당 서비스의 작업에 적용하고, 새 서비스의 목적·분야·지표·보유기간은 자체 명세와 승인된 계획에서 정한다. 실제 수행하지 않는 학습 활동의 기록을 만들 필요는 없다.

# 4 양식과 주기의 적용

### 4.1 지침서는 기존 양식 60종을 사용하며, 각 양식의 핵심 항목과 결정 근거를 충족하는 통합 기록을 사용할 수 있다. 통합 기록에는 양식 ID와 대응 구역을 표시하고, 같은 증거를 중복 첨부하는 대신 유효한 원본을 연결한다.

### 4.2 상세 검토는 [절차서 공통 적용 원칙](../procedure/AIDU-AIP-00.md)의 조건을 따른다. 일반 리스크 평가와 영향평가는 공통 양식으로 수행하고, 별도 기준·협의가 필요한 경우 06-01-F06 또는 06-02-F04를 추가한다. 법령 적용 판정 04-01-F05와 제공 전 투명성 확인 08-01-F09는 기본으로 수행하며, 08-01-F10은 고영향 또는 안전성 확보 책무가 적용되는 경우 사용한다.

### 4.3 연 1회 통합 점검, 반기 또는 계획 주기의 목표 점검, 상시·월별 운영 확인 및 변경·사건 발생 시 수시 검토를 적용한다. 단기 보유 만료, 긴급 보호, 법령·계약 기한을 정기 검토일까지 미루지 않는다. 지침서의 상세 작업 항목마다 별도 정기 회의나 보고서를 만들 필요는 없다.

### 4.4 체크 결과는 합격·불합격·보류·미실시·비해당을 구분하고 해당 버전의 근거를 연결한다. 양식 원본에 실제 결과를 덮어쓰거나 예시를 완료 기록으로 제출하지 않는다.
