## 공통 적용

절차서는 업무의 수행 시점·입력·처리·판단·검토·승인·출력과 양식의 필수 필드를 정한다. 방침·목표·평가 결과·SoA·역할 지정·작성된 기록은 별도 산출물로 관리한다. 각 절차의 5항은 빈 양식을 구성하기 위한 정의이며 실제 결과를 기입하는 본문이 아니다. [문서양식 목차](../forms/README.md)에 양식 60종의 개별 Markdown 원본을 연결하며, 각 절차의 양식번호에서도 해당 파일을 열 수 있다.

기능상의 역할과 현재 부서별 분장은 AIDU-AIP-05-02를 따른다. 인공지능안전관리자는 분장된 업무를 수행하는 담당 부서를 포함하며 모든 실무를 한 사람에게 집중시키는 역할을 뜻하지 않는다. 실제 담당자·대리·위임은 별도 지정 기록으로 관리한다.

신규 서비스는 AIDU-AIP-04-01의 상황·범위 검토에서 시작하여 해당 서비스의 요구사항·리스크·영향·목표·자원·검증·운영 조건을 별도 명세와 계획으로 결정한다. 기존 서비스의 평가 결론이나 설정을 그대로 적용하지 않는다.

양식 식별·매체·전자 승인·공식 저장소·보유·폐기는 AIDU-AIP-07-03을 공통 적용한다. 하나의 기록이 여러 양식의 필수 항목을 충족하면 대응 관계를 남겨 통합 관리할 수 있다. 각 절차에 정한 주기보다 법령·계약 또는 승인된 리스크 대응에서 더 빠른 조치가 필요하면 해당 기한을 적용한다.

## 참조 표준·법령의 적용

ISO/IEC 22989의 용어·역할·수명주기, ISO/TR 24368의 윤리 검토, ISO/IEC 23894 및 ISO 31000의 리스크 관리 지침을 실행 절차에 반영한다. 지침의 권고와 ISO/IEC 42001·매뉴얼의 요구, 법적 의무·노력의무·회사 운영 기준을 구분한다. 출처 판·조사일·조항별 대응은 [표준·법령 반영 근거](../analysis/aims-procedure-revision-basis.md)를 참조한다.

신규·변경 시스템은 04-01-F05로 법적 역할·고영향·생성형·안전성 적용을 검토한다. 06-01-F06에서 리스크 범위·기준·협의를 먼저 정하고 06-02-F04에서 윤리 대안·피영향자 의견을 기록한다. 제공 전 08-01-F09·F10으로 투명성·설명·감독과 적용되는 법정 책무를 확인한다. 회사의 위험 점수는 법적 고영향 판정을 대체하지 않는다.
