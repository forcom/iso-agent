## 2 대상과 적용 법령

| 항목 | 기입 내용·근거 또는 연결 기록 |
| --- | --- |
| 시스템·버전·목적·실제 고객 사용 | Edu Score — 학생이 제출한 객관식·단답형·서술형 답안과 에세이를 분석하여 점수를 산출하고 제한적 피드백과 AI 작성 확률을 제공한다. 목적은 교수자의 평가 활동 보조이다. 교육기관이 평가 기준을 등록하고, 교수자와 학생이 결과를 확인하여 학습 계획에 반영한다. 고객이 결과를 성적 확정·장학·징계 등에 어떻게 연계하는지는 확인되지 않았다(ISS-03). |
| 국가·관할·국내 영향 | 대한민국 — 국내 대학 5개, 국내 민간 LMS 10개, 국내 성인 학습자 5,000여 명. 국외 고객 없음. |
| 법·시행령·고시 원문·공포·시행·확인일 | 인공지능기본법(2025. 1. 21. 제정, 2026. 1. 22. 시행)과 같은 법 시행령(2026. 1. 22. 시행) — 국가법령정보센터 원문, 확인일 2026. 4. 13. / 일부개정 법률(법률 제21311호, 2026. 1. 20. 공포, 2026. 7. 21. 시행) — 공포·미시행으로 별도 관리(REQ-27) / 「개인정보 보호법」 현행 원문, 확인일 2026. 4. 13. |
| 회사·공급자·고객의 개발·제공·이용 행위 | 회사: 외부 모델(OpenAI API, Gemini API)을 호출하는 채점·피드백·판별 로직, 프롬프트, 가명처리 전처리, 결과 화면을 개발하여 서비스로 제공한다. 자체 모델 학습·파인튜닝은 없다. 공급자: 범용 AI 모델을 API로 제공한다. 고객: 서비스를 도입하여 소속 교수자·학습자가 이용하며, 일부 LMS는 결과를 자사 플랫폼에 표시한다. |
| 법적 역할·특별법·적용 제외 근거 | 법 제4조의 적용 제외(국방·국가안보 목적) 비해당. 교육 평가에 관하여 인공지능기본법보다 우선 적용되는 특별법상 AI 규율은 확인되지 않았다. 고객 측 성적 평가 권한은 고객의 학칙·고등교육 관계 법령에 따른다. |

## 3 고영향·생성형·안전성 판정

| 항목 | 기입 내용·근거 또는 연결 기록 |

| 생명·신체·기본권 영향·중대성·빈도·특수성 | 생명·신체 영향 없음. 기본권 영향: 평등권(문체·언어 편향), 알권리(설명가능성 한계), 사생활의 비밀(학습 정보) — 기존 영향평가서상 영향 규모 "높음". 평가 시점마다 반복 사용되므로 빈도가 높다. 성적은 장학·졸업·취업과 연결될 수 있다. |
| 인간 개입·자동화·권리와의 연결 | 회사 설계상 교수자가 결과를 확인하고 최종 반영한다. 그러나 교수자가 검토 없이 그대로 성적에 반영할 수 있는 구조이며(ISS-05), 실제 개입 수준은 확인되지 않았다. |
| 생성 기능·결과물·고지·표시 조건 | 피드백 텍스트는 생성형 AI가 생성하는 결과물이다. 점수와 AI 작성 확률도 생성형 모델의 출력에 기반하므로 표시 방식을 시스템 명세 확정 후 AIDU-AIP-08-01-F09에서 정한다. 실제와 구분 곤란한 음향·이미지·영상은 생성하지 않는다. |
