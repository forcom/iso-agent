## 3 분석·평가·수용 기준

| 항목 | 기입 내용·근거 또는 연결 기록 |
| --- | --- |
| 방법·정량/정성 선택 근거 | AIDU-AIP-06-01 4.2.4의 5단계 L×S 행렬을 기본으로 한다. 발생 근거(시험·운영 관찰·고객 응답)가 있는 리스크에만 L을 부여한다. 운영 분포 자료가 없거나 예비 시험 표본이 작아 L 추정이 결정을 왜곡할 수 있으면 정성 판정한다(같은 절차 4.2.6). |
| 가능성·심각도·시간·노출·집단별 판단 기준 | 심각도(S)의 Edu Score 해석 보충: S1 화면 오류 등 성적에 반영되지 않는 불편 / S2 성적 확정 전 교수자 검토로 정정되는 오류 / S3 확정 성적의 정정이 필요한 오류, 이의제기 부담 발생 / S4 학업윤리 회부·낙인, 수료 취소, 직장 내 인사 불이익처럼 회복이 어렵거나 다수·취약 집단에 집중되는 피해 / S5 퇴학·자격 박탈 등 회복 곤란한 중대 권리 침해 또는 광범위한 사회적 신뢰 붕괴. 회사·개인·집단·사회 각각 기록하고 최댓값을 적용한다(같은 절차 4.2.5 1)). |
| 행렬 사용 시 L의 시스템별 빈도 근거 | L은 "1개 학기 동안 통상 사용 조건에서 해당 사건이 발생할 근거"로 판단한다. L3은 예비 시험 또는 운영에서 사건이 1건 이상 관찰된 경우, L4는 고객 운영에서 반복 관찰되었거나 핵심 통제가 없는 경우, L5는 평가일 현재 발생 중인 경우로 해석한다. 소규모 표본에서 사건이 없었다는 사실만으로 L1을 부여하지 않는다(AIDU-AIG-08-01 4.3.4 2)). |
| 자료 신뢰도·불확실성·가능성 산정 불가 처리 | 예비 시험(표본 수십 건)은 발생 근거로만 쓰고 발생률로 표시하지 않는다. 공급자 비공개 정보는 "미확인"으로 두고 회사가 통제 가능한 보호 조치로 판단한다. 산정 불가 항목은 F02에 정성 판정 사유·추가 확보 자료·확보 담당·기한을 기록한다. |
| 누적·공통 원인·연쇄 위험의 결합 방법 | 같은 외부 API(OpenAI·Gemini), 같은 결과 화면, 같은 고객 활용 경로에 의존하는 리스크를 묶어 공통 원인과 연쇄 실패를 검토한다. 점수를 합산·평균하지 않고 복합 시나리오를 별도 ID로 등록한다(AIDU-AIG-08-01 4.3.6). |
| 통제 효과 인정 증거·민감도·재현 한계 | 현재 통제로 인정하는 증거: 운영 설정 화면, 배포 기록, 시험 결과, 운영 로그, 서명된 계약 조항. 문서·계획만 있는 통제는 인정하지 않는다(AIDU-AIG-08-01 4.3.3). 모델 출력의 비결정성 때문에 1회 시험 결과는 재현 한계를 함께 기록한다. |
| 수용 불가·우선순위·긴급 보호·승인 권한 | 수용 불가: 공통 기준(AIDU-AIP-06-01 4.2.7 1))에 더해 AI 방침 "추구하지 않는 사용" 1)·2)에 해당하는 사용이 운영 중이면 필수 보호 통제 미충족으로 본다. 우선순위: 긴급성 → 중대성 → 확산 범위 → 집단별 불균형 → 복합 영향(같은 절차 4.4.2 2)). R 10 이상은 신규 확대 보류와 임시 보호 조치를, 17 이상은 기능 즉시 중지·격리를 적용한다. 승인: 일반 처리·수용은 김철수, 중대 잔여 리스크·김철수 본인 관련 사안·사업 범위 조정은 윤승용(AIDU-AIP-05-02-F02-2026-001 S-13, AIDU-AIP-05-01-F03-2026-001 D-06·D-08) |
| 정성 수용과 낮음·보통 대응 근거 기준 | 정성 판정 리스크는 ① 필수 보호 통제의 작동 증거 ② 동일 조건 재시험 또는 1개월 이상 운영 관찰 ③ 해당 집단에 남는 영향 설명이 모두 있을 때만 "보통 이하에 상응"으로 판정하여 수용을 요청할 수 있다(AIDU-AIP-06-01 4.2.6 3)). |
| 기준 버전·승인일·변경 및 기존 평가 영향 | Edu Score 리스크 기준 v1.0(공통 기준 AIDU-AIP-06-01 2026. 4. 1. 시행본 + 본 계획서 보충) / 승인 2026. 5. 12. / 최초 기준으로 기존 평가 영향 없음. 변경 시 기존 F02 재평가 필요성을 확인한다. |
